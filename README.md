## The entry

One sentence, in the voice of a house cat, given in the five seconds after
sweeping a glass off the table — no apology, no confession, just the most
convincing case a cat can make for itself:

> That glass was squatting in my sunbeam rent-free, so I served it an eviction notice — one push, no appeal.

## Run it

```sh
python3 main.py
```

`main.py` prints the line and writes it to `/output/entry.txt`.
